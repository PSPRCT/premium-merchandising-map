# Version 7.9

## Manager Coverage & Placement Intelligence
- Store Intelligence > Open Manager now opens a real manager workspace.
- Manager names in Store Intelligence are clickable.
- Store Intelligence displays normalized Regional + District/Area hierarchy instead of the raw hierarchy key.
- Manager workspace includes stores, coverage, gaps, RTS support/dependency and manager-scoped placement opportunities.
- Placement opportunities are intentionally suppressed unless modeled impact is reasonable and concentrated.
- Surfaced opportunities can launch directly into Simulate New RTS.
- Manager scope and manager gaps can be pushed back to the live map.
