# Version 7.9.2

## Manager Intelligence drill-down
- Manager Intelligence now opens the full Manager Coverage & Placement Intelligence profile when a manager name/row is clicked.
- The prior map-only behavior is retained as an explicit `Map` button.
- Manager profile includes coverage, gaps, RTS dependency/support, and meaningful manager-scoped RTS placement opportunities.
- Regional Manager in the manager profile is clickable for upward hierarchy navigation.
- RTS dependency rows open the RTS profile directly.

This makes Manager Intelligence a true profile/navigation workspace instead of only a filter launcher.
