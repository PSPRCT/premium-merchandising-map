# Deployment

Upload the complete project to the GitHub Pages repository while preserving all
folders.

The Premium program reads data from:

- `data/premium-merchandising/stores.json`
- `data/premium-merchandising/rts.json`
- `data/premium-merchandising/metadata.json`

The original `data/stores.json`, `data/rts.json`, and `data/metadata.json` remain
in the package as rollback copies but are no longer the active Version 3 paths.
