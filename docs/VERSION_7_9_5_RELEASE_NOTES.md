# Version 7.9.5 — Authorized Position Planning

## Planning model
- One Walmart: maximum 100 RTS positions.
- Premium Merchandising: maximum 100 RTS positions.
- Existing active RTS positions are fixed/protected.
- The platform does not recommend relocation, replacement, or displacement of existing RTS.
- Remaining authorized capacity is calculated as 100 minus active RTS.

## Placement recommendations
New candidates are evaluated as scarce-capacity decisions rather than merely positive coverage changes.

Position Value Score:
- 50% net-new coverage
- 25% manager-footprint improvement
- 25% share of current gaps addressed

Competitive:
- 25+ net-new stores
- 15%+ manager footprint improvement
- 20%+ current gaps addressed
- Position Value score 60+

High Priority:
- 35+ net-new stores
- 20%+ manager footprint improvement
- 25%+ current gaps addressed
- Position Value score 75+

Lower-value candidates remain available for manual simulation and gap analysis but are not presented as staffing recommendations.
