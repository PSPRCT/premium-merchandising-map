# Version 7.3 — Premium Organization Hierarchy

Premium Merchandising now uses the same organizational navigation pattern as
One Walmart.

## Premium source mapping

- `2nd Level Mgr. Name` → Regional Manager
- `1st Level Mgr. Name` → District Manager
- `1st Level Mgr. Area/Mkt` → District / market identifier

Unneeded staffing, pay, position, and rep-detail columns are not used by the
coverage platform.

## Alignment

- Regional Managers: 18
- District Managers: 133
- Stores matched through District Manager: 9,048
- Stores identified directly to a Regional Manager: 351
- Stores unaligned: 74

The unaligned stores are retained rather than assigned by guesswork.

## Shared hierarchy

Both programs now support:

National → Regional Manager → District/Area Manager → RTS → Store
