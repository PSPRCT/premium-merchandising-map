# Version 6 — Intelligence Workspaces

## Critical consistency correction

The visible map, pins, popups, filters, and metrics now use the same rules as the
shared analytics engine:

- every RTS row on the applicable roster counts,
- eligibility is evaluated per store,
- One Walmart core and dedicated-team pools remain distinct,
- coverage uses the selected radius,
- stores are Gap, Unique, or Shared.
