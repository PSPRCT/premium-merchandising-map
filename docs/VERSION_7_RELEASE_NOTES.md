# Version 7 — Organization Navigator

## Added

- National → Regional Manager → Area Manager/RDM → RTS → Store hierarchy
- clickable breadcrumbs
- Regional Manager dashboards
- Area Manager dashboards
- automatic map focus at RM and RDM levels
- hierarchy exports
- user-supplied performance metrics:
  - % SO Executed
  - % Compliance
  - % SO Action Hours Utilized
  - % SO Action Hours Efficiency Gained

## Alignment

- Regional Managers: 12
- Area Managers/RDMs: 104
- Stores matched to hierarchy: 4,598
- Stores unmatched: 0

Store-to-RDM alignment uses the existing store `manager` field. RDM-to-Regional
Manager alignment uses the hierarchy supplied by the user.
